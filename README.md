# 可视化 MVU 面板

一个 **SillyTavern（酒馆）** 扩展：AI 回复里写了触发标记，就在那一楼挂一块可视化面板。你自己拖拽画出「变量区」，AI 按你的要求自动往里填值。

> 依赖 **酒馆助手（JS-Slash-Runner）** 与 **MVU（MagicalAstrogy/MagVarUpdate）**。

---

## 这是什么

大多数 MVU 卡的界面是**写死的**——作者决定显示什么变量、怎么显示。
这个扩展把决定权交给你：

- **在网格上拖一个矩形** → 新建一个变量区
- 选样式（进度条 / 文本 / 是或否 / 数值）、绑定 `stat_data` 里任意变量
- 写上**「告诉 AI 这里填什么」** → 临时注入上下文，AI 每轮都会读到并照着填

换卡不用重做布局，也不受作者怎么写卡限制。

## 安装

在酒馆里：**扩展（🧩）→ Install Extension**，填入本仓库地址：

```
https://github.com/fuli233i/visual-mvu-panel
```

装完**刷新页面**（Ctrl+F5）。

### 前置条件

| 依赖 | 说明 |
|---|---|
| **酒馆助手**（JS-Slash-Runner） | 必需。面板通过它的 API 读写变量、注入说明 |
| **MVU**（MagicalVarUpdate） | 必需。面板读写的是 MVU 的 `stat_data` |

两个都没装的话，面板不会出现（F12 Console 会提示 `没等到酒馆助手`）。

## 显示方式：AI 写了标记才出现

面板**不是**每条回复都挂。只有 AI 回复的正文里出现触发标记时，那一楼才会显示面板：

```
{visual-mvu}
```

`[visual-mvu]` 和 `<visual-mvu>` 也认。标记本身会被自动隐藏，不会露在正文里。

> ⚠️ 尖括号写法在酒馆里**会被 HTML 过滤吃掉**：`<visual-mvu>` 渲染后只剩下 `visual-mvu` 几个字。
> 扩展也认这种「裸文本」，但 `{visual-mvu}`（花括号）最稳。

面板会把这个约定**临时注入上下文**（用酒馆自带的扩展注入，不写世界书），AI 每轮都会读到，于是会自动在回复末尾带上标记。<br>**只在存在设置好的变量区时才注入** —— 所以新聊天要先手动给一条 AI 回复加上 `{visual-mvu}`（或者从别的聊天「导入布局」），面板出现后再拖变量区，之后这个聊天就自动了。
想换标记：改 `index.js` 顶部的 `TRIGGER_PATTERNS`；把它设成 `[]` 就回到「每条 AI 回复都挂面板」的旧行为。

> 标记请写在**整条回复的最末尾**（所有 `<UpdateVariable>` / `<JSONPatch>` 块之后）。面板会**等这一楼停止出字约 0.7 秒后才出现** —— 流式输出时酒馆每收到一段文字就会把正文整个重写一遍，提前挂上去的面板会被抹掉、看起来一直在闪。

### 让 AI 顺手改面板数值（可选）

有些卡的变量规则写死了「只允许写已定义字段」，AI 因此不肯把面板变量写进 `<UpdateVariable>`。
遇到这种卡，可以让 AI 把改动写在标记里，面板自己解析、自己写进变量树（不走卡的校验）：

```
{visual-mvu: 体力-5, 好感度=95}
```

数字增减用 `+N` / `-N`，整值用 `=值`，文本用 `="内容"`，是或否用 `=是` / `=否`，多项用英文逗号分隔。
没变化时只写 `{visual-mvu}` 就行。同一轮里如果这条路径已经出现在 `<JSONPatch>` 里，面板会跳过，不会加两次。

## 快速上手

### 1. 建一个变量区

在面板的网格空白处**按住鼠标左键拖出一个矩形**。松手后会出现一个虚线占位框：

```
┌────────────────┐
│  ＋ 点击此处设置  │
└────────────────┘
```

**点它**才弹出设置框（不会一拖完就弹窗糊你一脸）。

### 2. 配置

设置框分「基本」「样式」两页：

**基本**

- **变量路径** — 相对 `stat_data`，用 `.` 分层，如 `好感度` 或 `背包.金币`。路径在这一楼不存在时会**自动新建**：进度条/数值默认 `0`，文本默认「请输入文本」，是或否默认「否」
- **显示名** — 留空就用变量名
- **告诉 AI 这里填什么** — 重点，见下
- **展示样式** — 进度条 / 文本 / 是或否 / 数值 / **自定义文字** / **图片**
  - **自定义文字**：整块只显示你写的一段文字（可换行），不绑变量、AI 不碰它
  - **图片**：整块只放一张图片，**没有边框、没有底色**，可拖入 / 选文件 / 粘 URL，并能在 **-180°~180°** 之间旋转
- **修改内容** — 点它进入就地修改态，直接点卡片上的值改数

**样式**

数值范围、单位、进度条色调与粗细、标识（内置图标 / emoji / **图片可直接拖入**）、
字体字号、卡片背景色、**卡片文字颜色**（底色偏浅/偏深时用它把字调清楚）、
圆角开关、边框线型（虚线/实线）、边框颜色。

### 3. 「告诉 AI 这里填什么」怎么写

这是让 AI 填对值的关键。写清**取值范围**和**推进节奏**：

```
0=讨厌，50=有好感，100=深深爱上。
每次按当前剧情推进 1~5 点，重大事件可 ±10。
```

```
单位为枚，0~999。每次交易 ±10~50；
拾取宝箱时 +100。
```

```
只能是「是」或「否」。确认受伤后改为「是」，之后不再改回。
```

这些文字会被**临时注入上下文**（不写世界书），AI 每轮都会读到。

## 操作

| 操作 | 效果 |
|---|---|
| 删除变量区（卡片设置里的「删除」） | 会问「要不要连变量一起删」 |
| 拖卡片 | 移动位置 |
| 拖卡片右下角 | 缩放 |
| **按住 Alt 拖卡片** | 边缘自动对齐其它卡片，虚线提示 |
| **按住 Alt 缩放** | 被拖的那条边吸附到其它卡片的边线（同样有虚线提示） |
| 悬停网格滚轮 | 所有卡片整体上下平移（超出被裁） |
| **拖动中滚轮** | 可以边拖边滚，卡片不会跟丢鼠标 |
| 卡片右下齿轮 | 该变量区的设置 |
| 顶栏右上齿轮 | 面板设置 |

## 面板设置

分 5 页：

| 页 | 内容 |
|---|---|
| 主题颜色 | 色派（**淡 / 浓**）、15 个主题色、8 个独立强调色、**亮度 / 对比度**（100% = 不变，浅色主题嫌刺眼就压亮度） |
| 背景 | 面板/交互区/变量区底色（各 25 预设 + 彩虹取色）、网格、暗角、界面字体 |
| 布局 | 交互区高度 |
| 导入 / 导出 | 导出 JSON；导入可点选或**直接拖进去** |
| 危险操作 | 列出这一楼已创建的变量并勾选删除；清空所有变量区 |

**淡 / 浓两派**共用同一批色相，切换时自动换算明暗并带过渡动画。

### 布局按聊天分开

**每个聊天记录各存一套布局**，换聊天互不影响，新开的聊天是空白面板。**只有最新一条 AI 回复上的面板可以编辑**，往上翻的旧楼层显示为「历史楼层 · 只读」（看得到当时的状态，但拖不动、改不了）。
想把这套布局搬到别的聊天：面板设置 →「导入 / 导出」导出 JSON，到那边再导入。
而**数值读每一楼自己的变量**——所以往上翻旧楼层，看到的是当时的历史状态。
删掉最后一条回复（或回退到上一楼）时，变量自动回到那一楼的值：面板读的就是「这一楼自己的变量」；
如果那一楼还缺面板声明的变量，面板会自动按样式补出来。

## 常见问题

**面板不出现？**

1. 确认这条 AI 回复的正文里**有触发标记** `{visual-mvu}`（旧回复可能没带）
2. 确认酒馆助手已启用（本扩展完全依赖它）
3. F12 → Console，应能看到 `[可视化面板] 已启动`
4. 若提示 `没等到酒馆助手`，说明酒馆助手没加载
5. AI 漏写标记不用手动补：只要这个聊天里有**设置好的变量区**，说明每轮都会自动注入，AI 自然会补上；实在没有变量区时，给 AI 回复里手动添一句 `{visual-mvu}` 就能唤出面板

**AI 不填我新建的变量 / 不输出 `{visual-mvu}`？**

面板**不写世界书**，而是把说明临时注入上下文：

- 用酒馆自带扩展注入（`setExtensionPrompt`，IN_CHAT + 深度 4）直接塞进上下文，**一本世界书都不建**，也不留任何条目
- 只要这个聊天里存在「设置好的变量区」，就会自动注入；改布局、刷新页面、换聊天后都会自动重新注入

注入已经生效、AI 还是不照做的话，多半是**卡自己的约束**挡住了：例如卡的输出格式写着「不允许写入变量规则中没有定义的字段」，或卡的 zod 变量结构约束会把未定义字段过滤掉。面板新建的变量正是「卡里没定义」的字段，需要在卡那边放行。

**数值显示「（无此变量）」？**

`stat_data` 里没这个路径。现在保存卡片设置时会自动把变量建出来（默认值随样式），正常不会再看到；还显示的话，检查拼写与 `.` 分层的层级。

## 技术说明

- **挂载**：不用 iframe，直接往 `.mes_text` 里插 DOM，因此能直接用全局
  `TavernHelper` 读写变量，无需 postMessage 桥接。
- **样式隔离**：所有规则以 `#vmvu-root` 为前缀，不污染酒馆界面。
- **变量读写**：`TavernHelper.getVariables({type:'message', message_id})` /
  `replaceVariables(...)`，按楼层精确读写。
- **说明注入**：`SillyTavern.getContext().setExtensionPrompt()`（IN_CHAT + 深度 4）——**不写世界书**。
  旧版本往世界书写过 `[面板]…` 条目，启动时会自动清理一次。
- **布局存储**：酒馆助手的**聊天变量**（`insertOrAssignVariables(..., {type:'chat'})`），
  每个聊天各存一份；localStorage 按聊天分键兜底。

## 网络与隐私

- **不联网**：本扩展不发起任何网络请求（没有 `fetch` / XHR / WebSocket，也没有外部脚本、字体或图标 CDN）。
- **不收集**：不上传、不统计、不带遥测。布局、变量、设置全部只存在你自己的酒馆里
  （聊天变量 + 浏览器 localStorage），换设备不会跟着走。
- **唯一的例外**：变量区「标识」里允许你**手动填一个外部图片 URL**（也可以直接拖入图片，拖入的会压缩后存在布局里）。
  只有你填了那种 URL，浏览器才会去请求那个地址 —— 地址由你决定，扩展本身不预置任何域名。
